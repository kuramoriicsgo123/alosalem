# Boutique Discord ARK: Survival Ascended

Bot Python pour créer les catégories, salons, rôles, panneaux de vente avec boutons verts et tickets privés d'une boutique ASA. Boutique en anglais, installation en français.

**[Télécharger le programme en ZIP](https://github.com/kuramoriicsgo123/alosalem/archive/refs/heads/main.zip)**

## Installer sur Windows 11

1. Téléchargez le ZIP, puis faites **clic droit → Extraire tout**.
2. Installez Python 3.12 en cochant **Add python.exe to PATH**.
3. Ouvrez le dossier extrait et lancez **INSTALLER_WINDOWS.bat**.
4. Suivez **[README_FR.md](README_FR.md)** pour créer votre bot Discord, l'inviter et renseigner `config.json` et `.env`.
5. Lancez **DEMARRER_WINDOWS.bat** et gardez sa fenêtre ouverte.

Ne publiez jamais votre token Discord. Le fichier `.env`, la configuration personnelle et les données de tickets sont exclus de Git.

## Ce qui est inclus

- 11 catégories et 76 salons, avec un seul salon central de tickets.
- 54 panneaux de produits/services avec de vrais boutons Discord verts.
- Tickets privés, attribution au staff, commandes terminées, transcripts et reprise après redémarrage.
- Catalogue, prix, images et identité modifiables dans les fichiers JSON.
- Installation Windows et 46 tests automatiques hors ligne.

Le bot doit être invité et démarré pour agir sur votre serveur. La connexion Discord réelle et l'exécution sur Windows restent à valider chez vous. Les prix non choisis affichent **Contact Staff** ; les mécaniques ARK non confirmées sont signalées.

Voir aussi [le contrôle qualité](docs/CONTROLE_QUALITE_FR.md), [les prix publics relevés](RECHERCHE_PRIX_FR.md) et [les mécaniques ARK à vérifier](docs/MECANIQUES_ARK_FR.md).
